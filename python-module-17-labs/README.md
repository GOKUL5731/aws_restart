# AWS Python Introduction Practice — 17 Labs

The archive in this folder contains independently written practice implementations for the 17 numbered lab sections in the supplied AWS Introduction to Programming document (0 1 through 0 17). The supplied document does not contain 108 numbered labs, so this upload is explicitly scoped to those 17 sections.

Download and extract `aws_python_module_17_labs.tar.xz`. It contains the Python scripts, sample CSV/JSON data, and the lab index.

These are personal educational implementations, not an official AWS solution pack. The repository is public; do not upload AWS course manuals or restricted training material. No AWS credentials are included.
